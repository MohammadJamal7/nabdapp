يستخدم Service Account Private Key لإرسال إشعار مباشرة

👉 النتيجة ستظهر هنا

كيف تحصل على البيانات؟

  1. Firebase Console ← ⚙️ Project Settings ← Service Accounts
  2. اضغط Generate new private key ← حمل ملف JSON
  3. انسخ القيم التالية من الملف:
    project_id ← Project ID
    client_email ← Client Email
    private_key ← Private Key (كلها، من `-----BEGIN` ل `-----END`)
  4. انسخ FCM Token من Log التطبيق (fcmToken:)
